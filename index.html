Nudges,
without the fuss.

Nudgify is a lightweight notification library for the web. Add clear, customizable updates to your app with a small API and flexible styles.

Open the playground

Quick example

import { nudge } from "nudgify";

nudge.success("Your changes have been saved!", {
  position: "top-right",
  animation: "slide-up",
  duration: 4000,
});

Use nudge.info(), nudge.success(), nudge.warning(), or nudge.error(). The default nudge(message, options) creates an info nudge.

Customize your notifications

Positions & styles

Choose from six screen positions and default, soft, solid, outline, or glass variants.

Motion controls

Slide in any direction, flip, fade, scale, or bounce. Adjust animation duration and easing.

Interactive actions

Add callback buttons or safe links directly inside notifications.

Expandable stacks

Opt into overlapping stacks that expand on hover or keyboard focus.

Options

  • position: top/bottom left, center, or right.
  • animation: slide, slide-up/down/left/right, flip, fade, scale, or bounce.
  • animationDuration (milliseconds) and animationEasing (linear, ease, ease-in, ease-out, ease-in-out, or spring).
  • variant: default, soft, solid, outline, or glass; theme: light, dark, or auto.
  • duration in milliseconds (0 keeps a nudge open), borderRadius in pixels, icon, and closable.
  • stack: true overlaps notifications at the same position; defaults to false.

Nudge actions

Buttons accept an onClick callback; links accept an href using http, https, or mailto. Actions dismiss the nudge when activated.

nudge("Do you want to continue?", {
  duration: 0,
  actions: [
    { label: "Yes", onClick: () => confirmAction() },
    { label: "Learn more", href: "https://example.com" },
  ],
});

Installation

Install Nudgify with your preferred package manager, then import the nudge API in your app.

1. Install the package

npm install nudgify
# or
pnpm add nudgify
# or
yarn add nudgify

2. Import and show a nudge

import { nudge } from "nudgify";

nudge.success("You're all set!");

Available types are nudge.info(), nudge.success(), nudge.warning(), and nudge.error().

3. Customize it

nudge.success("Profile saved", {
  position: "top-right",
  animation: "slide-up",
  animationDuration: 350,
  animationEasing: "ease-out",
  duration: 4000,
});
