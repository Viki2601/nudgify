A little more about the project

Small nudges.
Clear communication.

Nudgify is a lightweight JavaScript library for adding helpful, customizable notifications to web apps—without making a simple message feel like a big integration.

The project

Useful feedback, made simple.

Give people timely feedback for the little moments that matter: a saved change, a warning, an error, or an action they can take right away.

01 / Lightweight

A small, direct API

Install the package, import nudge, and show a notification. Nudgify has no runtime dependencies.

02 / Flexible

Fits your interface

Choose from six screen positions, five visual variants, light or dark themes, and a range of motion and timing options.

03 / Interactive

More than a message

Show info, success, warning, and error nudges. Add callback buttons or safe links when a notification needs a next step.

04 / Try it

Explore before integrating

Read the installation guide for a quick start, then use the playground to experiment with the available options.
